## Введение

Markdown — это простой язык разметки для быстрого форматирования текста.

---

## Основные возможности Markdown

Заголовки, списки, жирный/курсив, ссылки, изображения, таблицы и блоки кода.

---

## Пример форматирования

**Жирный текст**, _курсив_, `код`, [ссылка](https://example.com).
