## Лабораторная работа №3. Работа с Markdown-разметкой

#### Что такое Markdown

Markdown — это лёгкий язык разметки, который используется для оформления README-файлов, документации, отчётов и даже научных текстов. Он прост в использовании и хорошо читается как в сыром виде, так и после рендеринга.

#### Где применяется

Markdown широко используется на GitHub, в VS Code, Obsidian, а также для написания блогов, документации и заметок.
